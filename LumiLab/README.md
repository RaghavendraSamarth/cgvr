> 🚀 **Live Interactive WebGL Showroom:** [https://lumilabs-one.vercel.app/](https://lumilabs-one.vercel.app/)

**LumiLab** is a premium, interactive virtual 3D lighting showroom and product configurator built in Unity. Users can inspect, customize, and experience architectural designer lamps in real-time across multiple realistic interior environments.

The project incorporates complete procedural 3D mesh generation, dynamic lighting calculations, real-time material shaders, interactive camera mechanics, local persistence, and a dedicated **Computer Graphics & Virtual Reality Case Study** demonstration module.

---

## 🌟 Key Features

### 1. 🪔 Procedural 3D Designer Lamps
All lamps are built entirely without external paid assets using mathematical procedural algorithms and Unity primitives:
* **Lamp 1 — Aura Modern:** Contemporary table lamp featuring a circular beveled base, slim metallic stand, tapered linen lampshade, and warm core illumination.
* **Lamp 2 — Nordic Glow:** Scandinavian-inspired organic lamp with a turned walnut timber base, sculptural ceramic gourd body, and soft woven shade.
* **Lamp 3 — Industrial Edge:** Architectural task lamp with a stepped cast-iron base, dual articulated friction arms, and an angled conical spotlight shade with directional beam optics.
* **Lamp 4 — Halo Contemporary:** Minimalist futuristic fixture with a polished chrome plinth and a luminous 360° emissive torus halo ring.

### 2. 🛋️ Realistic Showroom Environments
Seamlessly switch between three fully scaled, decorated architectural settings:
* **Environment 1 — Luxury Living Room:** Modern dark oak acoustic slat wood wall panels, polished hardwood floor, designer side table, and warm ambient evening illumination.
* **Environment 2 — Minimal Design Studio:** Clean neutral background, elevated pedestal platform, studio softbox illumination, and sharp product photography aesthetics.
* **Environment 3 — Cozy Bedroom:** Nightstand staging with warm interior bedroom tones, wall accents, and an intimate evening mood.

### 3. ⚙️ Deep Customization Studio
* **Dimensions & Proportions:** Live parametric adjustments for overall lamp height, base diameter, shade width, shade height, and shade style (tapered frustum vs. fluted drum).
* **Material Finishes:** Physically Based Rendering (PBR) finishes including brushed brass, mirror polished chrome, matte ceramic, Scandinavian walnut wood, frosted glass, and woven linen fabric.
* **Curated & Custom Color:** 6 curated designer color presets + custom RGB sliders with a real-time dynamic color swatch preview box.
* **Lighting Engine:** Primary power toggle, continuous brightness slider ($0.1\times$ to $2.5\times$), and calibrated color temperature buttons (Warm 2700K, Neutral 4000K, Cool 6500K).
* **One-Click Mood Presets:**
  * 🕯️ *Cozy Evening* (Warm 2700K light, walnut base, woven linen shade)
  * ⬜ *Modern Minimal* (Neutral 4000K light, matte white ceramic, crisp linen)
  * 👑 *Luxury Gold* (Brushed brass stand, warm gold shade accent)
  * ⚙️ *Industrial Black* (Matte cast-iron dark metal, intense focused spotlight)
  * 🌈 *Colorful Ambient* (Vibrant modern saturated mood lighting)
* **Save & Restore:** Local persistence powered by `PlayerPrefs` and JSON configuration serialization.

### 4. 🎥 Interactive Camera System
* **Smooth Orbit & Zoom:** Click-and-drag orbit rotation with elevation clamping (prevents clipping through floors) and smooth mouse wheel zooming.
* **Auto-Rotate:** Continuous turntable rotation with smooth damping.
* **View Presets:** Instant animated transitions between **3/4 Hero View**, **Front View**, **Side View**, **Top View**, and **Reset View**.
* **Smart Framing:** Focuses dynamically on the currently selected lamp.

### 5. 🎨 Dark Luxury Glass UI (Native Unity uGUI)
The UI is built with native Unity UI (`Canvas`, `Image`, `Text`, `Button`, `Slider`, `Dropdown`, `Toggle`) styled with the **Dark Designer Glass** aesthetic via [`ProceduralUIUtility.cs`](Assets/Scripts/UI/ProceduralUIUtility.cs):
* **Palette Tokens:** Deep Studio `#0c0d10`, Frosted Glass `#14161b`, Card Well `#1a1d24`, Slate Border `#272b35`, and Champagne Gold `#d4af37`.
* **Dynamic 9-Slice Rounded Sprites:** Autogenerated antialiased procedural textures for smooth rounded cards and pills at runtime without relying on external UI sprite packs.
* **Collapsible Drawers:** Left Lamp Collection drawer and Right Customization drawer with hamburger toggles.

## 🔬 Case Study 2 — Computer Graphics & VR Architecture

An interactive academic demonstration panel accessible via the **`Case Study 2 🔬`** button in the top navigation:

1. **2D CAD Profile to 3D Mesh (Lathe Revolution):**
   * Revolution of parametric 2D spline curves $P(u) = (r(u), y(u))$ around the central $Y$-axis:
     $$V(\theta, u) = \begin{pmatrix} r(u)\cos\theta \\ y(u) \\ r(u)\sin\theta \end{pmatrix}, \quad \theta \in [0, 2\pi]$$
   * Dynamic radial tessellation slider ($N = 6 \dots 48$) with real-time vertex, triangle, and normal recalculation.
2. **Boundary Representation (B-Rep) Topology:**
   * Procedural hollow solid with explicit topological boundary surfaces (inner cylinder, outer cylinder, top rim, and bottom annular cap).
   * Live Euler-Poincaré formula verification on the hollow solid:
     $$V - E + F = 2(s - g) = 0 \quad (\text{Genus } g = 1)$$
3. **Geometric Transformations & $4 \times 4$ Homogeneous Matrix:**
   * Real-time composite transformation matrix display ($M = T \cdot R \cdot S$):
     $$\mathbf{M} = \begin{bmatrix} S_x \cos\theta & 0 & S_x \sin\theta & T_x \\ 0 & S_y & 0 & T_y \\ -S_z \sin\theta & 0 & S_z \cos\theta & T_z \\ 0 & 0 & 0 & 1 \end{bmatrix}$$
4. **Viewing, Projection & Wireframe:**
   * Dynamic Field of View (FOV) perspective projection slider ($15^\circ \dots 90^\circ$).
   * Live wireframe rendering toggle and real-time performance HUD (FPS, memory allocation, batch metrics).

## 🚀 Running the Project

### Option A: Launch WebGL in Your Browser (No Unity Required)

A complete, uncompressed WebGL distribution is pre-built in [`Builds/WebGL/`](Builds/WebGL/):

1. **One-Click:** Double-click [`run_webgl.bat`](run_webgl.bat) in the root directory.
2. The script starts a local web server and opens:
   👉 **`http://localhost:8080/index.html`**

*(Or manually run `cd Builds\WebGL; python -m http.server 8080`)*

---

### Option B: Open and Run in Unity Editor

1. Open **Unity Hub** (Unity **6000.6.7f1** recommended).
2. Add and open the project directory: `c:\Users\priya\Unity\LumiLab`.
3. Open the main scene:
   [`Assets/Scenes/LumiLab_Showroom.unity`](Assets/Scenes/LumiLab_Showroom.unity)
4. Press **Play (▶)**.
   * [`LumiLabRuntimeShowroom.cs`](Assets/Scripts/Core/LumiLabRuntimeShowroom.cs) runs automatically via `[RuntimeInitializeOnLoadMethod]`, instantly verifying and wiring all lighting, lamps, camera, and the UI.

## 🌐 Live WebGL Deployment

* **Live Studio Link:** **[https://lumilabs-one.vercel.app/](https://lumilabs-one.vercel.app/)**

The WebGL build in [`Builds/WebGL/`](Builds/WebGL/) is completely standalone with compression disabled (`WebGLCompressionFormat.Disabled`), meaning it runs out-of-the-box on **any** static host without configuring gzip/brotli server headers:

### Deploy to Netlify / Vercel (1 Minute Drag & Drop)
1. Navigate to [app.netlify.com/drop](https://app.netlify.com/drop) or [vercel.com](https://vercel.com).
2. Drag and drop the `Builds/WebGL` folder directly into the window.
3. Your 3D studio will be published immediately to an active HTTPS link!

### Deploy to GitHub Pages
1. Push this repository to GitHub.
2. In your repo settings, go to **Settings → Pages**.
3. Choose the source branch and set the folder to `/` (or push `Builds/WebGL` to a dedicated `gh-pages` branch).
4. Access your live showroom at `https://<your-username>.github.io/<repo-name>/`.
